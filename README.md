Используетcя файл `.csv`

- **LOAD** - загрузка константы, принимает два аргумента - адрес и константу
- **READ** - читает данные из памяти, принимает 3 аргумента - адрес откуда читать, адрес в какой регистр читать и смещение
- **WRITE** - записывает данные в память, принимает два аргумента - из какого регистра читать, адрес регистра хранящий адрес памяти, куда писать
- **SQRT** - выполняет операцию извлечения корня, аргументы аналогичны **READ**

*Пример*

LOAD;54;4;

READ;3;67;181

WRITE;8;126;

SQRT;85;16;753
